# HUMAN//OPS × Make.com

Make.com is an **execution surface** for HUMAN//OPS. It does not decide authority. The HUMAN//OPS Judge determines whether a signal is safe to automate, requires AI-assisted human judgment, must be escalated, or should be queued.

## Core scenario

```text
External event
    ↓
Make webhook
    ↓
Normalize payload
    ↓
POST /api/judge
    ↓
HUMAN//OPS Judge
    ↓
Make Router
 ┌────────────┬────────────┬────────────┬────────────┐
 ↓            ↓            ↓            ↓
AUTOMATE    AUGMENT     ESCALATE      QUEUE
 ↓            ↓            ↓            ↓
Execute      Prepare      Stop +       Persist
bounded      context      notify       context
work         + draft      human        for later
 └────────────┴────────────┴────────────┴────────────┘
                  ↓
             Log action
                  ↓
             Watch outcome
                  ↓
           HUMAN//OPS Watcher
```

## Judge request

Send a JSON signal to `POST /api/judge`.

```json
{
  "id": "sig-1001",
  "source": "email",
  "summary": "Client says they may cancel if implementation is not fixed this week",
  "intent": "churn_risk",
  "urgency": 96,
  "value": 98,
  "risk": 94,
  "confidence": 91,
  "reversibility": 23,
  "humanConsequence": 94,
  "humanJudgment": 97,
  "createdAt": "2026-08-22T09:30:00-04:00"
}
```

## Judge response

```json
{
  "signal": { "...": "original signal" },
  "decision": {
    "signalId": "sig-1001",
    "mode": "ESCALATE",
    "reason": "human consequence or judgment threshold exceeded; risk threshold exceeded",
    "policy": "HFAF-A3",
    "requiresHuman": true
  }
}
```

## Make routes

### AUTOMATE
Use only for bounded, reversible, high-confidence, low-consequence work. Example actions: send a routine document, update CRM fields, create a task, schedule within pre-approved constraints, or execute a standard support response.

### AUGMENT
Make may gather account history, retrieve relevant records, draft a recommendation, prepare a briefing, and notify the named human. It must not silently convert an AUGMENT decision into autonomous execution.

### ESCALATE
Stop the autonomous branch. Create a human decision package, name an owner, notify the appropriate channel, and wait for an explicit human action or approval event.

### QUEUE
Persist the signal with full context and a reason for deferral. The Capacity Brain or Watcher can later reopen it when urgency, workload, dependency state, or timing changes.

## Watcher callback

A later API endpoint will accept action and outcome events from Make. The Watcher will compare the expected outcome with the observed state, detect overdue or failed loops, and reopen work when the outcome did not occur.

## Revenue Operations demo

The first external demonstration can use synthetic revenue events:

- routine inbound leads
- high-value enterprise leads
- missing qualification data
- duplicate leads
- pricing exceptions
- contract or privacy questions
- negative sentiment / churn risk
- booking failures
- unresponsive prospects
- overloaded account owners

The demo should report only measured results generated by the running scenario. No performance claims should be hard-coded or fabricated.
